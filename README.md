# 随笔工坊 · Essay Desk

> *Hone Your Voice.*

在 **DeepSeek Harness** 的 Web GUI 里写随笔、按主题归档、沉淀思想脉络，并每天写一道命题的插件。

进入插件后，左侧是两个功能入口：

- **随笔**：写作面板。左栏是「未分类」草稿与「主题」列表，右栏是标题 + 正文编辑区：手动保存、`Ctrl/Cmd+S`、停止输入约 1 秒自动保存、删除（移入归档备份）、实时字数。在对话里说「帮我整理随笔」，DSH 会通读未分类草稿，归纳主题，把每篇归档进 `主题/<主题名>.md`，原稿移入 `未分类/_已整理/` 留档；说「总结一下我的思想变化」或「帮我梳理关于 xx 的想法」，DSH 会跨篇提炼，把阶段性总结追加到 `思想脉络.md`，并在对话里给出观察。
- **命题演绎**：每天一道命题的写作练习。可以开启每日推送（到点在面板里生成任务），也可以随时点「领取今日命题」主动出题；写完后提交，DSH 按题目自带的「反馈标准」逐条写评语并发积分。每个完成的任务都会留下任务记录（日期 / 标题 / 状态 / 积分 / 评语），直接显示在面板里。

命题演绎首页还会汇总累计积分、已完成任务数和连续写作天数。

所有文字都落盘成本地 Markdown，默认放在工作区目录下的 `随笔/` 文件夹，可在「设置」里改。

## 安装

这是一个标准 DSH bundle（含 `cordis.patch.yml` 与 `dsh.client` 声明）：

```text
dsh-essay-desk/
├── index.js          Host 半侧：存储 + HTTP API + Agent 工具 + 系统提示段落
├── client.js         Client 半侧：Web GUI 面板（main 槽 + sidebar.panellist 图标）
├── package.json      bundle 清单（dsh.bundle / dsh.client）
├── cordis.patch.yml  Loader 行声明
├── locale/{zh,en}.json  插件管理器显示用的标题与描述
└── icon.svg
```

把本目录放到任意工作目录，然后用 Harness 的插件管理安装这个本地 bundle
（或把包名加入 profile 的 `dsh.profile.bundles`）。安装后刷新 Web 页面，侧栏会出现「随笔」图标。

## 数据位置

默认根目录：**工作区目录下的 `随笔/` 文件夹**（插件按自身安装路径推断工作区；无法推断时退回 `~/.dsh/essays`）。首次启动自动创建，并会把旧版 `~/.dsh/essays` 里的数据整体迁移过来。

```
随笔/
├── 未分类/<id>.md           草稿（# 标题 + 正文）
├── 未分类/_已整理/<id>.md   归档后的原稿备份
├── 主题/<主题名>.md         每个主题一个文件
├── 思想脉络.md              按日期追加的阶段性总结
├── 练习/任务/<YYYYMMDD>.md  每日写作练习任务（题目 + 我的演绎 + 评语 + 积分）
└── 练习/积分.json           写作练习累计积分与历史
```

### 修改存放位置

优先级：环境变量 `ESSAY_DESK_ROOT`（绝对路径）> `<DSH_HOME>/essay-desk.json` 中的 `{ "root": "..." }` > 工作区默认目录。

也可以在面板右上角「设置 → 文件与目录 → 存放位置」里直接改，留空即恢复默认，改完立即生效。

```json
{
  "root": "/Users/你/我的随笔",
  "practice": {
    "enabled": true,
    "time": "09:00",
    "keywords": "旧照片, 站台, 误会"
  }
}
```

- `practice.enabled`：是否每天自动生成练习任务（默认 `true`）。
- `practice.time`：推送时间，`HH:mm`（默认 `09:00`）。Harness 启动时若已过该时间且当天没有任务，会自动补生成。
- `practice.keywords`：命题关键词提示（逗号/空格分隔）。生成时优先匹配带相关标签的题目，并把关键词写进命题。

## Agent 工具

工具 `essay`：

| action | 作用 |
|---|---|
| `list` | 未分类草稿（id / 标题 / 字数 / 日期）与主题（篇数）总览 |
| `read` | 读一篇草稿、某个主题文件或 `思想脉络.md` |
| `write` | 新建或修改未分类草稿 |
| `classify` | 把草稿归档进主题，支持 `items` 批量；可轻微润色标题、不改正文 |
| `note` | 向 `思想脉络.md` 追加一段按日期的总结 |

插件还会注入一段系统提示，告诉 Agent 这个随笔库的约定，任何会话都能直接整理。

工具 `practice`：

| action | 作用 |
|---|---|
| `list` | 练习任务列表（日期 / 标题 / 状态 / 积分 / 评语摘要）与累计积分 |
| `read` | 读某天的任务全文：题目、我的演绎、评语 |
| `score` | 按任务「反馈标准」写评语并发积分（10–20），状态置为已评 |
| `generate` | 生成/补生成某天的练习任务 |
| `config` | 读取当前练习配置与存放位置 |

## 命题演绎

1. 打开「命题演绎」入口，首页显示今日命题、累计积分、已完成、连续天数，以及全部任务记录（带评语摘要）。
2. 想自己出题：点「领取今日命题」（已有当天任务时直接打开，不会覆盖）；想自动出题：在「设置 → 命题演绎」里打开每日推送并设时间，到点自动在 `练习/任务/` 生成当天任务。
3. 点开任务，在「我的演绎」里写，**保存草稿** → **提交**。
4. 在对话里说「练习写完了 / 帮我评分」，DSH 会按题目自带的 4 条反馈标准逐条点评，并发放积分（基础 10 + 0–10 加分）。
5. 评语与积分写回任务文件，`练习/积分.json` 累计；任务记录与首页统计刷新即可看到。

### 出题约定

- 角色不标注性别，第三人称统一用 `ta`（`他们/她们` → `ta们`）。
- 每期随机指定主视角：front matter 写 `pov: 男|女`，「约束」里写明「本期主视角：第一人称（男性视角/女性视角）」。`pov` 只代表叙事视角，不代表作者性别。
- 题库包含以社会身份（职业/身份）为角色的框架，例如代驾司机×乘客、夜班护工×家属、房东×租客、外卖骑手×保安。
- 不生成性少数 / 非异性恋关系题材；`practice.keywords` 里若出现相关词，会在生成时被过滤掉。

积分目前只用于记录与正反馈；能兑换什么、要不要做徽章/连续天数，等后续再设计。

## 文件格式

草稿：`# 标题` + 空行 + 正文。

主题文件由归档时自动维护：

```markdown
# 主题名

## 随笔标题

*2026-10-28 20:30*

正文……

---
```

## 开发与校验

纯 ESM + 纯 JS，无构建步骤、无外部依赖。

```bash
node --check index.js
node --check client.js
```

Host 半侧的全部纯函数（`resolveRoot` / `listState` / `saveDraft` / `classifyDraft` / `appendNote` / `generatePracticeTask` …）均已导出，便于在临时目录中做单元测试。

改完 `index.js` / `client.js` 后：插件源码不在 HMR 监视范围，触发一次 profile 重新组合（改一下 `~/.dsh/profiles/desktop/cordis.patch.yml` 或重启 Harness）即可加载新代码；界面半边刷新页面即可。

## 说明

- HTTP 接口只监听回环地址请求，并限制请求体 2 MB。
- 定时生成由 Host 每 60 秒检查一次；当天已有任务不会重复生成，`enabled=false` 时停止生成；「领取今日命题」不受 `enabled` 限制。
- 归档不删除原稿：原文件移动到 `未分类/_已整理/`。
- 面板内不可归档；归档由 Agent 在对话中通过 `essay` 工具完成，保证主题归纳的一致性。
- 改「存放位置」后，旧位置的数据不会自动搬过去（默认目录迁移只在旧版 `~/.dsh/essays` 上做一次），需要的话可手工复制。
